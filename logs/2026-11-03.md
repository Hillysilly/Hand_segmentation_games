# 2026-11-03: Quest 3 AR game

**Where it stands:** a Unity project in `unity_game/` runs on the Quest 3 with four hand-tracked weapons
in passthrough. The laser and wall stopping came out well, but the aura still isn't good. **Nothing was
committed to git in this session.**

## What got built

- **Environment:** a Unity 6000.6.7f1 project with OpenXR, AR Foundation, Meta OpenXR, XR Hands and URP.
  Setup and builds are scripted, and `unity_game/build_and_run.ps1` builds, installs and launches the game.
- **Test game:** orange orbs float in the room, with a score and a HUD.
- **Weapon switching:** an "OK" sign cycles through the weapons.

| Weapon | How it works | Status |
|---|---|---|
| **Repulsor** | Fist to charge, snap open to fire | Played; a fix for random shot directions went in, with no numbers on it yet |
| **Laser** | Hold palm out for a beam of light with an impact burst and sparks | Best result so far, at 72 FPS with two beams firing |
| **Shockwave** | Same gesture as the repulsor; fires a widening ring | Built and tested in code; never seen fired |
| **Aura** | Hold palm at someone to light flames around them | **Not good yet** |

## What worked

- **Stopping at real surfaces:** the laser found a real surface on about 95% of frames in the one session
  measured, using live depth with no room scan.
- **The laser look:** it went from a plain cylinder to thick radiating light.
- **Room dimming:** the room dims while firing, and the laser sound has a new ignite crack, roar and
  sizzle. No feedback yet on these, and the sounds aren't confirmed working.

## Bugs found

- **Missing Meta library:** the setup script turned off a hidden Meta feature, `OpenXRLifeCycleFeature`,
  so every early build was missing `libUnityARFoundationMeta.so`. The game looked fine, but Meta's
  features weren't loading. Fixed, and `QuestBuild` now fails if the library is missing.
- **Wrong passthrough proof:** the `xrPassthroughStartFB` log line first given as proof came from the
  Quest's system shell, not the game. Passthrough does run from the game now.
- **Zigzag beam:** tapering the beam's mesh caused it, so the taper moved into the pixel shader.
- **Orbs on the floor:** they spawned before head tracking had started.

## Aura: where it ended

It went through three versions: soft streaks that buried the person, then a clean outline that looked
flat, then three layers of flames that still weren't good.

**The biggest open question is the depth cut-out.** The aura was never captured on the headset, so it's
unknown whether the cut-out works, and every look was tuned on a PC preview with a stand-in shape. That's
probably why it kept missing. It also doesn't follow people yet; it stays where it was lit.

## Not confirmed yet

- Whether the fix for random shot directions works; no session recorded the data
- The new orb-pop sparks, never seen on the headset
- Whether the laser's impact burst lies flat on walls, floors and tables
- The aura's frame rate with all three layers

## Decisions

- **Suits are on hold:** they'd be hard on another person, because the game can't erase someone from
  passthrough. Gauntlets alone felt underwhelming.
- **Open source:** the code is fine to release, but `suit.glb` and `spiderman.glb` aren't, because credit
  doesn't cover Marvel's designs. They're in git history, so a public release should use a fresh repo.
  The GitHub repo is private for now.
